# Go Operational Insights SDK

# Go Operational Insights SDK 1.0

The Operational Insights Go SDK allows you to connect to an [Operational Insights](#entreprise-analytics:intro:intro.adoc) cluster from Go. For connecting to a Couchbase Server Cluster — self-managed, or Capella Operational — see our [Go Operational SDK](../../../go-sdk/current/hello-world/overview.md).

> [!TIP]
> Connecting to an [Operational Insights _Capella_](#columnar:intro:intro.adoc) cluster from Go currently requires a [Go Columnar SDK](../../../go-columnar-sdk/current/hello-world/overview.md).
