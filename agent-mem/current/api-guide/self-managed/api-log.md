# The Agent Memory API Change Log

This page covers all changes for the Agent Memory API.

## [](#release-1-1-0)Version 1.1.0

Released Agent Memory API 1.1.0\. For older Agent Memory API versions, see [Version 1.0.0](../../../1.0/api-guide/self-managed/api-log.md#release-1-0-0).

### [](#october-2026)October 2026

| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
