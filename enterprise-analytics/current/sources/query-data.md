# Query Data

> To query data stored externally, you create an external link and associate it with an external collection. 

In Enterprise Analytics, you can query data through the following service providers:

* [Query Data in Amazon S3](external-s3.md)
* [Query Data in Google Cloud Storage (GCS)](external-gcs.md)
* [Query Data in Azure Blob Storage](external-azureblob.md)
