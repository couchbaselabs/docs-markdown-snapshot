# System Event Reference

> A complete list of Couchbase-Server system events. 

The system events listed on this page are generated by Enterprise Analytics in response to calls made with the REST API. The system events are classified according to the service or component that generates them: these are [Cluster Manager](#cluster-manager), [Analytics Service](#analytics-service), and [Security](#security).

For an overview of system events, see [System Events](#learn:clusters-and-availability/system-events.adoc). For information about using the REST API to return system events, see [Getting System Events](rest-get-system-events.md).
