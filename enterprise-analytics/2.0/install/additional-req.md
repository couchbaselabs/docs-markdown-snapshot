# Additional Requirements

> Depending on your local configuration, you might need to install or configure some additional system requirements to use Enterprise Analytics. 

## [](#java-runtime-environment-jre)Java Runtime Environment (JRE)

OpenJDK 21 is installed when you install Enterprise Analytics. Only [HotSpot-based JVMs](https://openjdk.java.net/groups/hotspot/), which include the ones provided by OpenJDK and Oracle’s JDK, are supported. If you plan to use an alternative JRE, the following versions are supported.

__Table 1\. Supported Java Runtime Environments__
| **Implementation** | **Version** |
| ------------------ | ----------- |
| Oracle JRE         | Version 21  |
| OpenJDK            | Version 21  |
