# Tracing

> Tracing and Metrics provide fine-grained insight into how an application is performing, and helps to diagnose when it is not. 

> [!WARNING]
> Response Time Observability is not supported in Node.js SDK 4.0\. View [the Node.js SDK 3.2 docs](#3.2@response-time-observability)RTO support will be available in a later 4.x release. See the [SDK 4.0 migration considerations](../project-docs/migrating-sdk-code-to-3.n.md#sdk4-specifics).
