# Power BI

> The Couchbase Power BI Connector provides integration between tabular views of your Operational Insights collections, or query results of those tabular views, and the Microsoft Power BI interactive data visualization platform. 

For information about setting up the connector, see the [Introduction](../../../power-bi-connector/current/index.md) documentation.
