# Tableau

> The Couchbase Tableau Connector provides integration between tabular views of your Operational Insights collections, or query results of those tabular views, and the Salesforce Tableau interactive data visualization platform. 

> [!NOTE]
> Operational Insights services are only compatible with the Couchbase Tableau Connector for Desktop and Server version 1.1.3 and later.  
> You can download the latest version of the Couchbase Tableau Connector from the [Release notes](../../../tableau-connector/current/release-notes.md) page.

For information about setting up the connector, see the [Introduction](../../../tableau-connector/current/index.md) documentation.
