# Error Codes

> The error codes that Operational Insights returns, with their messages and what they mean. 

When a request fails, the response contains an `errors` array. Each entry has a numeric `code` and a `msg`. The following tables list each error code with its message, and describe when the error occurs and what to do about it. In messages, `[string]` stands for a value that is filled in when the error occurs, such as a name or a number.

### 20xxx Codes (authorization)

| Code  | Message                                                              | Description                                                                                                                                                                                                                                                                                                                        |
| ----- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 20000 | Unauthorized user.                                                   | The request could not be authenticated: no credentials were supplied, or the username and password or client certificate were not accepted. It is also raised when the data service rejects the credentials used to stream data into a link. Check the credentials and retry.                                                      |
| 20001 | Insufficient permissions or the requested object does not exist      | The user is authenticated but does not hold the role needed for the statement or REST call, for example read access to a collection the query uses, or permission to manage a link. The same error is returned when the object does not exist, so that its existence is not disclosed. Check the object name and the user's roles. |
| 20002 | Invalid credentials for link \[string\]                              | The remote cluster rejected the username and password configured on the named remote link, either because the user does not exist there or the password is wrong. Update the link's credentials with ALTER LINK or the links REST API.                                                                                             |
| 20003 | Link authentication failed: \[string\]                               | Authentication with the remote cluster of a remote link did not complete: the remote cluster returned an unexpected response during the handshake, or none of its nodes could be reached. The value shown gives the reason. Check that the remote cluster is running and reachable from every node, then retry.                    |
| 20004 | Access denied: user lacks necessary permission(s) to access resource | The user is authenticated but is not permitted to call the REST endpoint, or the user configured on a remote link lacks the permission the remote cluster requires for the operation. Grant the missing role to the user concerned.                                                                                                |

Supply a value of the type shown.                                                                                                                |
| 21019 | Parameter '\[string\]' or '\[string\]' is required if '\[string\]' is provided                                                     | A parameter was supplied that needs one of two other parameters alongside it, and neither was given. Add one of the two named parameters.                                                                                                                                                                                                            |
| 21020 | Parameter '\[string\]' is not allowed if '\[string\]' is provided                                                                  | Two parameters that cannot be combined were both supplied, typically two different authentication methods in the definition of a link or external collection, such as an access key together with an instance profile. Keep only the parameters for the method you intend to use.                                                                    |
| 21021 | Invalid value for parameter '\[string\]', allowed value(s): \[string\]                                                             | The named parameter of a link or external collection accepts only a fixed set of values, and the value supplied is not one of them. Use one of the values listed.                                                                                                                                                                                    |
| 21022 | Cannot pause cluster due to active stream \[string\]                                                                               | A request to pause the cluster was refused because the named link is still connected and ingesting data. Disconnect all links, then retry the pause.                                                                                                                                                                                                 |
