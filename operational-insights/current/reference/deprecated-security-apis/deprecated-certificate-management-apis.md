# Deprecated Certificate Management APIs

> A number of certificate management APIs are deprecated. 

The APIs listed in this section, on the page [Upload and Retrieve the Root Certificate](upload-retrieve-root-cert.md), are deprecated. Use instead the methods and endpoints listed and summarized on the page [Certificate Management API](../rest-certificate-management.md).
