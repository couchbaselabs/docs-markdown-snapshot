# Manage Settings

> Couchbase-Server _settings_ can be established by the administrator. 

## [](#couchbase-server-settings-overview)Settings Overview

The _settings_ for Operational Insights can be accessed via Operational Insights Web Console. Navigate to the **Settings** section in the left-hand navigation menu.

By default, this displays the **General** settings panel. The settings interface contains multiple tabs along the top control bar, from which different settings categories can be selected.

The available settings categories are:

* **General** \- Allows configuration of _name_, _memory quotas_, _storage modes_, and _node availability_ for the cluster; and of _advanced settings_ for the Index and Query Services. These are described in [General](general-settings.md).
* **Alerts** \- Enables notification of critical system events to users. These are described in [Alerts](configure-alerts.md).
