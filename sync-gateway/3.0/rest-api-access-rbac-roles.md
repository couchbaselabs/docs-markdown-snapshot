## [](#admin)Admin

The table below identifies the RBAC roles required by Sync Gateway to execute endpoint actions. **Couchbase Server 7.0.2 Developer Preview** introduces new roles offering fine grained access control; existing roles will remain available.

For more on RBAC roles, see the Couchbase Server documentation: [Couchbase Server Authorization Roles](../../server/current/learn/security/roles.md)
