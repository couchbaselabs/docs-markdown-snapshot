# Error Messages

> The standardized error codes returned by the Analytics .NET SDK, from Capella connection to SQL++ query. 

The .NET Analytics SDK passes through the Analytics error codes from Enterprise Analytics.

For a full list of error codes, see [Analytics Error Codes](../../../server/current/analytics/error-codes.md).
