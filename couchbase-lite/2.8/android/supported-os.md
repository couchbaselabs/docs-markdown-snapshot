# Supported Operating System Versions

> Description — _Couchbase Lite on Android — the OS and SDK versions on which this framework is supported_  
> Related Content — [What’s New](../../current/cbl-whatsnew.md) | [Release Notes](#couchbase-lite:android:{cbl-pg-releasenotes}) | [Compatibility](../../current/android/compatibility.md)

## [](#officially-supported-versions)Officially Supported Versions

The operating systems listed below refer to "Certified" versions of Android. We do not test against, nor guarantee support for, uncertified Android versions such as versions built from source.

> [!IMPORTANT]
> Deprecation Notice
> 
> Support for API 19 and 21 was deprecated in release 2.6 and will be removed in a future release
> 
> _Action:_ Please plan to migrate your apps to use API versions greater than API 21

| Platform | Runtime architectures | Minimum API Level |
| -------- | --------------------- | ----------------- |
| Android  | armeabi-v7a           | 22                |
| Android  | arm64-v8a             | 22                |
| Android  | x86                   | 22                |
| Android  | x86\_64               | 22                |
