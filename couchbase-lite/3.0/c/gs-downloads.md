## [](#introduction)Introduction

_Couchbase Lite for C_ is available for all [Supported Platforms](supported-os.md). You can obtain downloads for _Linux_ and _macOS_ from the links here in the downloads table.

For _Android_, _iOS_ and _Windows_ downloads, see the Couchbase Downloads page here — [Extend with Mobile](https://www.couchbase.com/downloads#extend-with-mobile); for Windows debug symbols — see links here in the downloads table.

Alternatively, check the [install](gs-install.md)page, for how to get the software using a package manager.

Ensure you select the correct package for your application’s compiler and architecture.

Alternatively, check the [install](gs-install.md)page, for how to get the software using a package manager.

Ensure you select the correct package for your application’s compiler and architecture.
