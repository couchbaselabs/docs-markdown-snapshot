# Release Notes for Couchbase Fleet Manager

## [](#release-1-0-0)Release 1.0

FleetManager 1.0.0 was released in October 2026\. This initial release introduces Couchbase Fleet Manager and contains the following capabilities.

Initial Release

Introducing Couchbase Fleet Manager — a new, self-hosted companion product for tracking your Couchbase usage.

Fleet Manager gives you a single view of your usage across your entire fleet — clusters, nodes, cores, and RAM — and tracks it against your contracted entitlements.  
It runs entirely in your own environment, with no data leaving your network, and supports air-gapped deployments.  
Fleet Manager collects usage data from Couchbase Server clusters running version `7.6.12` or `8.0.3+`.  
To get started with Fleet Manager, contact your Couchbase account manager or [Couchbase Support](../../server/current/introduction/contact-couchbase.md).

See the [Fleet Manager documentation](introduction.md) for details.
