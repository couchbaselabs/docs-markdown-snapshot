# Error Messages

> The standardized error codes returned by the Operational Insights Python SDK, from Cluster connection to SQL++ query. 

The Python Operational Insights SDK passes through the Analytics error codes from Operational Insights.

For a full list of error codes, see [Analytics Error Codes](../../../server/current/analytics/error-codes.md).
