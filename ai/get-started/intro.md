# Capella AI Services

Capella AI Services provide you with the tools to create your own agentic and retrieval-augmented generation (RAG) AI applications. These services integrate seamlessly with the Couchbase Capella cloud platform, enabling you to develop your AI applications on the same platform as your data.

## Core Services

###  Capella Model Service

Deploy and manage Large Language Models (LLMs) and embedding models in Capella to power your AI-driven applications.

[Learn more](../build/model-service/model-service.md)

###  Capella AI Services Workflows

Use Capella AI Services Workflows to prepare, process, and vectorize text for use with other Capella AI Services.

[Learn more](../build/vectorization-service/data-processing.md)

###  Capella Agent Catalog

Use the Couchbase Agent Catalog to help manage tools and prompts for your own custom AI agents, using your preferred Large Language Model (LLM) and agent framework.

[Learn more](../build/integrate-agent-with-catalog.md)

###  Capella AI Functions

Use AI Functions to summarize text, classify content, detect sentiment, explain patterns, and more — all within your SQL++ queries.

[Learn more](../build/ai-functions.md)

## Start Building

###  Host an AI Model in Capella

Deploy an [embedding model](../build/model-service/deploy-embed-model.md) or [LLM](../build/model-service/deploy-llm-model.md) alongside your data.

###  Vectorize Your Data

Vectorize your [structured](../build/vectorization-service/vectorize-structured-data-capella.md) and [unstructured data](../build/vectorization-service/vectorize-unstructured-data.md).

###  Build an Agent

Create an [agentic app](../agent-tutorial/about-agentic-app.md) using the [Capella Agent Catalog](../build/integrate-agent-with-catalog.md) and use [Agent Tracer](../build/agent-tracer/agent-tracer.md) to monitor and observe agent activity.

###  Use the AI Services APIs

[Manage deployments with AI Services APIs](../api-guide/api-intro.md).
