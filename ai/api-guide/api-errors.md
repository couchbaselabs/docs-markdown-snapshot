# AI Services API Errors

> An explanation of error messages generated by the Couchbase AI Services Management API and the Model Service API. 

This page is for Capella AI Services. For Capella operational, see [Management API Errors](../../cloud/management-api-guide/management-api-errors.md).

API errors occur when a request fails to complete, typically returning standardized HTTP status codes that indicate the type and cause of the failure.

This API error reference lists:

* [Management API error messages](#management-api-errors)
* [Model Service API error messages](#model-service-api-errors)

## [](#management-api-errors)Management API Error Messages
