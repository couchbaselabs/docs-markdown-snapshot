# Get Involved

## [](#contributing)Contributing

Couchbase welcomes community contributions to the Node.js SDK. The [Node.js SDK source code](https://github.com/couchbaselabs/columnar-nodejs-client) is available on GitHub. Please see the [CONTRIBUTING](https://github.com/couchbaselabs/columnar-nodejs-client/blob/main/CONTRIBUTING.md) file for further information.

## [](#other-ways-to-contribute)Other Ways to Contribute

Other Ways to Contribute

* Join the discussion in our [forum](https://forums.couchbase.com/) and on our [Discord server](https://discord.com/invite/sQ5qbPZuTh).
* Improve the documentation — [bug reports and pull requests are welcome](https://docs.couchbase.com/home/contribute/index.html).
