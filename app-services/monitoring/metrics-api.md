# Use the App Services Metrics REST API

> App Services can be monitored by extracting metrics data using the App Services REST API. 

## [](#accessing-metrics-through-the-rest-api)Accessing Metrics through the REST API

The App Service metrics are also accessible through a secure REST API in the [Prometheus format](https://prometheus.io/).

For details, see [Capella App Services Metrics API Reference](../references/rest%5Fapi%5Fmetric.md).
