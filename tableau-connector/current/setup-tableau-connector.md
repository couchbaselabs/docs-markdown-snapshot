# Set up the Couchbase Tableau Connector

Before you can set up the Couchbase Tableau Connector, you must download the Tableau Connector package from one of the following locations.

## [](#downloading-from-couchbase)Downloading from Couchbase

The connector is distributed as a ZIP archive which you can download from the [Release Notes](release-notes.md) page. The ZIP archive includes the Couchbase Analytics **.taco** file and the **Couchbase JDBC driver** file, along with a **README** file.

## [](#downloading-from-tableau-exchange)Downloading from Tableau Exchange

Alternatively, you can download the connector directly from the Tableau Exchange [Couchbase Analytics](https://exchange.tableau.com/connectors/627) page. The page contains links to download the Couchbase Analytics **.taco** file, along with the **Couchbase JDBC driver** file.
