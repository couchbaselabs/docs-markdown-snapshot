# More Options Menu

A **More Options** menu is represented by 3 vertical ellipses in the UI (⋮).

When you need to describe a **More Options** menu in the UI:

* Refer to the menu as the **More Options** (⋮) menu.
* Use the HTML entity, `&vellip;` for the vertical ellipses.
* Use the [Menu UI Macro](menu-ui-macro.md) to describe any navigation inside a **More Options** menu. For example, go to **More Options** (⋮) > **Delete**.
