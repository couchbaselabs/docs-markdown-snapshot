# Supported Cloud Providers

Capella Analytics services supports deploying clusters on the below cloud service providers:

* [Amazon Web Services (AWS)](aws.md)
* [Google Cloud Platform](gcp.md)

> [!NOTE]
> The cloud service providers for Capella Analytics are different from those in Capella operational. To see the details of the cloud service providers for Capella operational, see [Supported Cloud Providers](../../cloud/clouds/cloud-providers.md).

> [!CAUTION]
> In the event of unexpected unavailability of the Cloud Service Provider’s remote object storage, the Capella Analytics service may experience temporary interruptions. Once the storage is available again, the service may take a few minutes to ensure data consistency before resuming normal operations.
