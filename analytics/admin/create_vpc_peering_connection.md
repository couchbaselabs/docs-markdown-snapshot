# Create VPC Peering Connection

As an alternative to creating a list of allowed IP addresses, Virtual Private Cloud (VPC) peering provides an added layer of security by avoiding communication over the Internet.

It can also reduce latency and egress costs, as well as the time spent managing access for individual addresses.

Capella Analytics services allows you to create VPC Peering with the below service providers:

* [Amazon Web Services (AWS)](vpc-peering.md)
* [Google Cloud Platform (GCP)](vpc-peering-gcp.md)
* [Microsoft Azure](vpc-peering-azure.md)
