# Error Messages

> The standardized error codes returned by the Columnar Go SDK, from Capella connection to SQL++ query. 

The Go Columnar SDK passes through the Analytics error codes from Columnar.

For a full list of error codes, see [Analytics Error Codes](../../../server/7.6/analytics/error-codes.md).
