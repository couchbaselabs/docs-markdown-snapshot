# Release Notes

## [](#october-2026-changelog)October 2026 Changelog

* Initial release  
We're excited to announce that AI Data Plane Managed MCP Server is now available.  
Remove the infrastructure and operational overhead requirements of hosting your own Couchbase MCP Server and easily access and interact with data in your Couchbase Capella operational clusters.  
For more information, see [Connect Data to Agents with Managed MCP Server](../about-managed-mcp.md).
