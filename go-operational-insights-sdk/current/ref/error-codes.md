# Error Messages

> The standardized error codes returned by the Go Operational Insights SDK, from cluster connection to SQL++ query. 

The Go Operational Insights SDK passes through the Analytics error codes from Enterprise Analytics.

For a full list of error codes, see [Analytics ServiceError Codes](../../../server/current/analytics/error-codes.md).
