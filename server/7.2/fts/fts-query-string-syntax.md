# Query String Syntax

> Query strings enable you to describe complex queries using a simple syntax. 

Using the query string syntax, the following query types can be performed:

* [Boosting](fts-query-string-syntax-boosting.md)
* [Date Range](fts-query-string-syntax-date-ranges.md)
* [Escaping](fts-query-string-syntax-escaping.md)
* [Field Scoping](fts-query-string-syntax-field-scoping.md)
* [Match Phrase](fts-query-string-syntax-match-phrase.md)
* [Match Query Syntax](fts-query-string-syntax-match.md)
* [Numeric Range](fts-query-string-syntax-numeric-ranges.md)
