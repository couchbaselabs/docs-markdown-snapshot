# Compound Queries

Compound Queries

Accept multiple queries simultaneously, and return either the _conjunction_ of results from the result-sets, or a _disjunction_.

The following queries are compound queries:

* [Conjuncts & Disjuncts](fts-supported-queries-conjuncts-disjuncts.md)
* [Boolean](fts-supported-queries-boolean-field-query.md)
