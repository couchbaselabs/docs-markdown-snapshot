# Range Queries

Range Queries

Accept ranges for dates and numbers, and return documents that contain values within those ranges.

The following queries are range queries:

* [Numeric Range](fts-supported-queries-numeric-range.md)
* [Date Range](fts-supported-queries-date-range.md)
* [Term Range](fts-supported-queries-term-range.md)
