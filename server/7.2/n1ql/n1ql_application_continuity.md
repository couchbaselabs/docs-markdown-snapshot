# SQL++ Application Continuity

No special strategy is required to ensure SQL++ application continuity during Couchbase Server upgrades if you are already running Couchbase Server 5.0 or later. If you are on a pre-5.0 release, special care must be taken to ensure SQL++ application continuity if 5.x is part of your upgrade path.

Refer to [Upgrading Couchbase Server](../install/upgrade.md) for more information about upgrade paths.
