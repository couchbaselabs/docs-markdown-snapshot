# Advanced Features

## Flex Indexes

Flex Indexes provide the ability for a SQL++ query to use a Full Text Search index transparently with standard SQL++ syntax.

* [Flex Indexes](n1ql-language-reference/flex-indexes.md)

## Cost-Based Optimizer

The cost-based optimizer takes into account the cost of memory, CPU, network transport, and disk usage when choosing the optimal plan to execute a query.

* [Cost-Based Optimizer](n1ql-language-reference/cost-based-optimizer.md)

## SQL++ Support for Couchbase Transactions

SQL++ offers full support for Couchbase ACID transactions.

* [SQL++ Support for Couchbase Transactions](n1ql-language-reference/transactions.md)

## Time Series Data

In Couchbase Server 7.2 and later, SQL++ enables you to store and query time series data.

* [Time Series Data](n1ql-language-reference/time-series.md)
