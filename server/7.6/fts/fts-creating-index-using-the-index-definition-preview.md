# Using the Index Definition Preview

The _Index Definition Preview_ appears to the right-hand side of the **Edit Index** screen. Following index-definition, the upper portion may appear as follows:

![fts index definition preview](_images/fts-index-definition-preview.png) 

The preview consists of the JSON document that describes the current index configuration, as created by means of the user interface. By left-clicking on the **copy to clipboard** tab, the definition can be saved.
