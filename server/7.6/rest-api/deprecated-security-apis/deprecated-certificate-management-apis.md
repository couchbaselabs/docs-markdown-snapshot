# Deprecated Certificate Management APIs

> [!IMPORTANT]
> Couchbase Server Enterprise Edition 7.6 reaches End of Life on March 31, 2027\. Please upgrade to 8.0.x by following [Upgrade](https://docs.couchbase.com/server/current/install/upgrade.html), or contact [Couchbase Support](https://support.couchbase.com/hc/en-us).

> A number of certificate management APIs are deprecated. 

The APIs listed in this section, on the page [Upload and Retrieve the Root Certificate](upload-retrieve-root-cert.md), are deprecated in Couchbase Server Verion 7.1 and later. Use instead the methods and endpoints listed and summarized on the page [Certificate Management API](../rest-certificate-management.md).
