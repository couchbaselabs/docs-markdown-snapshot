# Metrics Reference

> [!IMPORTANT]
> Couchbase Server Enterprise Edition 7.6 reaches End of Life on March 31, 2027\. Please upgrade to 8.0.x by following [Upgrade](https://docs.couchbase.com/server/current/install/upgrade.html), or contact [Couchbase Support](https://support.couchbase.com/hc/en-us).

> A list of the metrics used by Couchbase Server. 

Metrics are provided for all Couchbase Services, and also for the Cluster Manager and XDCR. Metrics can be queried by means of the REST API explained at [Statistics](../rest-api/rest-statistics.md).

In this section, metrics are listed according to service, as follows:

* [Data Service Metrics](data-service-metrics.md)
* [Query Service Metrics](query-service-metrics.md)
* [Index Service Metrics](index-service-metrics.md)
* [Search Service Metrics](search-service-metrics.md)
* [Eventing Service Metrics](eventing-service-metrics.md)
* [Analytics Service Metrics](analytics-service-metrics.md)
* [Backup Service Metrics](backup-service-metrics.md)
* [Cluster Manager Metrics](ns-server-metrics.md)
* [XDCR Metrics](xdcr-metrics.md)
