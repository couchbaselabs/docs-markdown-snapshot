# Couchbase EFCore Release Notes

> Release notes and download archive for \`Couchbase.EntityFrameworkCore\`. 

This database provider allows Entity Framework Core to be used with Couchbase Database. The provider is maintained as part of the [Couchbase EFCore Project](https://github.com/couchbaselabs/couchbase-efcore-provider).

## [](#latest-release)Couchbase EF Core 1.0 Releases

We always recommend using the latest version of the Couchbase EF Core Provider — it contains all of the latest security patches and support for new and upcoming features. All patch releases for each dot minor release should be API compatible, and safe to upgrade; any changes to expected behavior are noted in the release notes that follow.

### [](#version-1-0-0-11-april-2025)Version 1.0.0 (11 April 2025)

Version [1.0.0](https://jira.issues.couchbase.com/issues/?jql=project%20%3D%20%22CBEF%22%20AND%20fixVersion%20%3D%20%221.0.0%22) is the initial release of the Couchbase EF Core Provider.
