The Couchbase Capella UI is supported by the following browsers with Javascript enabled:

| Browser           | Supported Version     |
| ----------------- | --------------------- |
| **Google Chrome** | Latest stable release |

Other browsers — particularly those based upon the same technology as Chrome — are likely to work, but for support and best performance with this release please use the latest version of Google Chrome.
