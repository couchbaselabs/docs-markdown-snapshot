# Organization Roles

> Use organization roles in Couchbase Capella to manage the privileges of your organization's users. 

Every [user account](manage-organization-users.md) in Couchbase Capella has an organization role that determines the privileges they have for Capella UI access inside that organization.

Use [projects](../projects/projects.md) and [project roles](../projects/project-roles.md) to grant more specific privileges and access to clusters, data, and data tools. Use [cluster access credentials](../clusters/manage-database-users.md) to manage your programmatic and application-level access to a cluster's data.

The following table describes the available organization roles and their privileges.

__Table 1\. Organization Roles__
| Role                                   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Organization Owner**                 | An Organization Owner can: Access the Capella UI Invite and manage [organization users](manage-organization-users.md) View and manage organization settings View and manage [billing](../billing/billing.md) View and manage all [projects](../projects/projects.md) in the organization View and manage [API keys](../management-api-guide/management-api-start.md) in the organization View and manage [SSO realms and teams](ui-auth/add-sso-auth.md) Manage [Capella iQ](../get-started/capella-iq/work-with-capellaiq.md) View and manage [upgrade maintenance jobs](../clusters/upgrade-database.md) View and create [support tickets](../support/manage-support.md) Organization Owners automatically have the [Project Owner](../projects/project-roles.md#project-owner-role) project role for all projects in the organization. An organization must have at least 1 user with the **Organization Owner** role at all times. |
| **Project Creator**                    | A Project Creator: Can create [projects](../projects/projects.md) Has all privileges granted by the [Organization Member](#organization-role-member) role Project Creators automatically have the [Project Owner](../projects/project-roles.md#project-owner-role) project role for any project that they create.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Organization Member**                | An Organization Member can: Access the Capella UI View organization settings View [organization users](manage-organization-users.md) View [projects](../projects/projects.md) where they're a member View [teams](ui-auth/manage-role-mapping.md) View and create [support tickets](../support/manage-support.md) Organization Members have privileges in a project based on their [project role](../projects/project-roles.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Organization Read-Only Member**      | An Organization Read-Only Member can: Access the Capella UI View organization settings View [organization users](manage-organization-users.md) View all [projects](../projects/projects.md) and [clusters](../clusters/view-database.md) in the organization View [AI Data Plane Services](../../ai/get-started/intro.md) View [support tickets](../support/manage-support.md) View [teams](ui-auth/manage-role-mapping.md) Organization Read-Only Members do not have access to cluster data.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Organization Billing Administrator** | An Organization Billing Administrator can: View and manage billing: Access the Capella Billing tab Manage [payment methods](../billing/billing.md#payment-options) View [billing overview](../billing/usage-invoices.md#access-billing) View [usage reporting](../billing/usage-invoices.md#filter-usage) View and create [billing alerts](#billing/about-billing-alerts.adoc) View and create [support tickets](../support/manage-support.md) with the **Billing** category Access the [Billing Management REST API](../management-api-reference/index.md#tag/Billing) Organization Billing Administrators do not have any project privileges.                                                                                                                                                                                                                                                                                        |
| **Organization Billing Viewer**        | An Organization Billing Viewer can: View billing: Access the Capella Billing tab View [billing overview](../billing/usage-invoices.md#access-billing) View [usage reporting](../billing/usage-invoices.md#filter-usage) View [billing alerts](#billing/about-billing-alerts.adoc) View and create [support tickets](../support/manage-support.md) with the **Billing** category Access the [Billing Management REST API](../management-api-reference/index.md#tag/Billing) in read-only mode Organization Billing Viewers do not have any project privileges.                                                                                                                                                                                                                                                                                                                                                                          |
