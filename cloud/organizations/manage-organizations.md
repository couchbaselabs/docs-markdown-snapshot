# Manage Organizations

## [](#create-an-organization)Create an Organization

To create an organization, you must first create a Couchbase Capella account.

Refer to [Create a Couchbase Capella Account](../get-started/create-account.md).

## [](#leave-an-organization)Leave an Organization

Refer to [Remove a User (or Yourself) from an Organization](manage-organization-users.md#remove-user).

## [](#delete-an-organization)Delete an Organization

To completely delete an organization, you will need to do the following:

1. [Delete all databases](../clusters/delete-database.md).  
Deleting ensures that no remaining resources will accrue charges in Capella.
2. **Contact Couchbase Capella Support**  
Couchbase Support will help you settle any remaining billing obligations and delete your organization.

For instructions on how to request support, refer to [Request Support](../support/manage-support.md).
