# .NET Operational Insights SDK 1.0

The .NET Operational Insights SDK allows you to connect to an Operational Insights cluster using C#. For connecting to a Couchbase Server Cluster — self-managed, or Capella Operational — see our [.NET Operational SDK](../../../dotnet-sdk/current/hello-world/overview.md).

> [!TIP]
> Connecting to a [Operational Insights _Capella_](../../../operational-insights-cloud/intro/intro.md) cluster from .NET is not currently possible.
