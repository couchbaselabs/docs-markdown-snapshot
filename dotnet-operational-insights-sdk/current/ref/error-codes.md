# Error Messages

> The standardized error codes returned by the Operational Insights .NET SDK, from Operational Insights connection to SQL++ query. 

The .NET Operational Insights SDK passes through the Analytics error codes from Operational Insights.

For a full list of error codes, see [Analytics Error Codes](../../../server/current/analytics/error-codes.md).
