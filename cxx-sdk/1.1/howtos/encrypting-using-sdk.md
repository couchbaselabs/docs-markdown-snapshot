> The Field Level Encryption library enables encryption and decryption of JSON fields, to support FIPS-140-2 compliance. 

This feature is available in the C++ SDK from [version 1.2.0](../../current/howtos/encrypting-using-sdk.md). For a high-level overview of this feature, see [Field Level Encryption](../../current/concept-docs/encryption.md).
