# Field Level Encryption from the SDK

> The Field Level Encryption library enables encryption and decryption of JSON fields, to support FIPS-140-2 compliance. 

This feature is available in the C++ SDK from [version 1.2.0](../../1.2/howtos/encrypting-using-sdk.md). For a high-level overview of this feature, see [Field Level Encryption](../../1.2/concept-docs/encryption.md).
