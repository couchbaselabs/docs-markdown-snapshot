# Get Involved

> Get involved with Couchbase’s Open Source SDKs. 

## [](#contributing)Contributing

Couchbase welcomes community contributions to the C++ SDK. The [C++ SDK source code](https://github.com/couchbase/couchbase-cxx-client) is available on GitHub. Please see the [CONTRIBUTING](https://github.com/couchbase/couchbase-cxx-client/blob/master/CONTRIBUTING.md) file for further information.

## [](#other-ways-to-contribute)Other Ways to Contribute

* Join the discussion in our [forum](https://forums.couchbase.com/) and on our [Discord server](https://discord.com/invite/sQ5qbPZuTh).
* Improve the documentation — [bug reports and pull requests are welcome](https://docs.couchbase.com/home/contribute/index.html).
