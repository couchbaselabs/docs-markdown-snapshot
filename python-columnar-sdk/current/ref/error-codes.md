# Error Messages

> The standardized error codes returned by the Columnar Python SDK, from Capella connection to SQL++ query. 

The Python Columnar SDK passes through the Analytics error codes from Operational Insights (Capella).

For a full list of error codes, see [Analytics Error Codes](../../../server/7.6/analytics/error-codes.md).
